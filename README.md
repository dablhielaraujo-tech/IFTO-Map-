# IFTO Map — Campus Palmas

Mapa interativo com navegação GPS pelas passarelas e corredores do IFTO Campus Palmas.

## Como publicar o site sem o seu nome no link

1. No GitHub, crie uma **Organização** gratuita chamada **`ifto-map`** (assim o link do site ficará `https://ifto-map.github.io/site/`).
2. Dentro dessa organização, crie um repositório público chamado **`site`** (ou **`ifto-map.github.io`** para ficar ainda mais curto: `https://ifto-map.github.io/`).
3. Envie todos os arquivos deste pacote para o repositório.
4. Vá em **Settings → Pages → Branch: `main` / `(root)` → Save**.
